# WinSecureAI-PS
WinSecureAI-PS is an AI-powered vulnerability framework for Windows. It uses WMI/CIM and the Gemini Pro API to automate misconfiguration detection and generate intelligent remediations. Findings are mapped to NIST, CIS Benchmarks, and MITRE ATT&amp;CK standards, bridging the gap between automated scanning and context-aware security fixes.
